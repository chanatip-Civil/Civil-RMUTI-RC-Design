# ข้อความสำหรับเริ่มงานกับ Claude (คัดลอกทั้งหมดด้านล่างไปวางในแชตใหม่)

> วิธีใช้: แนบไฟล์ zip ของโปรเจกต์ (หรือเชื่อมโฟลเดอร์โปรเจกต์ในแอป Claude) แล้ววางข้อความนี้
> แก้ `<MODULE>` เป็น module ของคุณ (Column / Beam / Slab / Stair / Footing) และ `<งาน>` เป็นงานที่จะทำ

---

นี่คือโปรเจกต์ **Civil RMUTI Rc Design** — โปรแกรมออกแบบโครงสร้างคอนกรีตเสริมเหล็ก
(Python 3.12 + PySide6 desktop, เว็บเวอร์ชันใน `web/`, ไฟล์โครงการ `.rcproj` เป็น JSON)
ที่ทีมกำลังพัฒนาร่วมกัน ฉันรับผิดชอบ module **<MODULE>**

**ก่อนเขียนโค้ด ให้ทำตามลำดับนี้:**

1. อ่าน `README.md`, `CONTRIBUTING.md`, `docs/DECISIONS.md` และโค้ดเดิมที่เกี่ยวข้อง:
   `app/design/base.py`, `app/design/fields.py`, `app/design/results.py`,
   `app/calculations/base_engine.py`, `app/design/<module>/`, `app/calculations/<module>_calculation.py`,
   `web/src/core.js` (บล็อก `SPECIFIC.<module>` และ `ENGINES.<module>`), `tests/`
2. รัน `python -m pytest` เพื่อยืนยันว่าโค้ดเดิมทำงานก่อนแก้
3. สรุปสั้น ๆ ว่าจะแก้ไฟล์ไหนบ้าง แล้วรอฉันยืนยัน

**กฎที่ต้องทำตาม:**

- ต่อยอดจากโค้ดเดิม **ห้ามสร้างระบบใหม่ทับ** ห้ามเปลี่ยนสถาปัตยกรรม, รูปแบบไฟล์ `.rcproj`, หรือหน้าจอ
- แก้เฉพาะไฟล์ของ module <MODULE> ตามตารางใน `CONTRIBUTING.md` ข้อ 2
  ถ้าจำเป็นต้องแก้ไฟล์ส่วนกลาง ให้บอกฉันก่อนและอธิบายเหตุผล — อย่าแก้เอง
- ช่องกรอกใหม่ให้เพิ่มผ่าน `FIELD_SPECS` (GUI สร้างให้อัตโนมัติ) ไม่ต้องเขียนหน้าจอใหม่
- การคำนวณอยู่ใน `CalculationEngine` แยกจาก GUI เสมอ คืนผลเป็น `DesignResult`
- **ห้ามใส่สูตรหรือค่าคงที่ที่ไม่มีแหล่งอ้างอิง** ทุกสูตรต้องมี comment ระบุมาตรฐานและเลขข้อ
  ถ้าไม่แน่ใจเลขข้อหรือค่าในมาตรฐาน ให้ถามฉัน อย่าเดา
- มาตรฐานที่ทีมตกลงใช้: ดู `docs/DECISIONS.md`
- เขียน test สำหรับทุกสูตร (กรณีผ่าน, ไม่ผ่าน, ค่าขอบ, มาตรฐานที่ไม่รองรับ) และระบุแหล่งที่มาของตัวอย่าง
- แก้ `web/src/core.js` ให้ได้ผลเหมือน Python และเพิ่มกรณีใน `tests/test_web_parity.py`
  แล้วรัน `python tools/build_web.py`
- ใช้ PEP 8, type hints, docstrings, ชื่อตัวแปรที่มีความหมาย
- เสร็จแล้วรัน `python -m pytest` ให้ผ่านทั้งหมด และบอกฉันว่าแก้ไฟล์อะไรบ้าง เพราะอะไร

- Beam: "เพิ่มการออกแบบเหล็กเสริมรับโมเมนต์ของคานหน้าตัดสี่เหลี่ยมเสริมเหล็กรับแรงดึงอย่างเดียว"
- Slab: "เพิ่มการวิเคราะห์พื้นทางเดียวด้วยสัมประสิทธิ์โมเมนต์ตามมาตรฐาน"
- Stair: "เพิ่มการคำนวณน้ำหนักบรรทุกและโมเมนต์ของบันไดพาดช่วงตามยาว"
- Footing: "เพิ่มการตรวจหน่วยแรงแบกทานและแรงเฉือนทะลุของฐานรากเดี่ยว"
